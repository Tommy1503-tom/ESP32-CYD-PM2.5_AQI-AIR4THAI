# ESP32-CYD-PM2.5_AQI-AIR4THAI
เวอร์ชันนี้ดึงข้อมูลจาก Air4Thai แทน Modbus TCP และมีไฟล์ฟอนต์ไทยรวมมาในโปรเจกต์แล้ว Error `ld returned 1` ของรอบก่อนน่าจะหายไปด้วย เพราะสาเหตุน่าจะเป็นไฟล์ฟอนต์ที่ขาด แต่ผมยังไม่ได้คอมไพล์กับบอร์ดจริง (เครื่องที่ผมใช้ลง PlatformIO ของ ESP32 ไม่ได้)

ตรรกะการอ่าน JSON ผมทดสอบบนคอมกับข้อมูลจำลองแล้ว ผ่านทั้งกรณีเจอสถานี ไม่เจอ และสถานีไม่มีค่า PM2.5 ส่วนรูปแบบ JSON จริงผมเปิดไฟล์ของ Air4Thai ตรงๆ ไม่ได้ (เว็บบล็อกการเข้าถึงอัตโนมัติ) จึงอ้างอิงจากตัวอย่างโค้ดที่คนอื่นเผยแพร่ ถ้าอ่านค่าไม่ขึ้น ให้ดู Serial Monitor แล้วส่งบรรทัด `[HTTP]` และ `[AQI]` มาให้ผม

## วิธีใช้
1. แตก zip แล้วเปิดโฟลเดอร์ `proj` ด้วย PlatformIO
2. แก้ใน `src/main.cpp`:
   - `WIFI_SSID` และ `WIFI_PASS`
   - **`STATION_ID`**: ตอนนี้เป็น `"02t"` ซึ่งผมไม่ได้ตรวจว่าเป็นสถานีที่ไหน ให้เปิดลิงก์ Air4Thai ในเบราว์เซอร์ ค้นหาชื่อพื้นที่ของคุณ แล้วคัดลอกรหัสที่อยู่ในช่อง `stationID` ของสถานีนั้นมาใช้
3. Build และ Upload

## การทำงาน
- ดึงข้อมูลทุก 5 นาที (ข้อมูลของสถานีอัปเดตรายชั่วโมง) ไฟล์ของ Air4Thai ใหญ่เกินกว่าจะเก็บใน RAM ของ ESP32 โค้ดจึงอ่านเป็นสตรีมและเก็บเฉพาะสถานีที่เลือก
- หน้า 1 แสดงเวลาปัจจุบัน, เวลาที่อ่านค่า, ชื่อสถานีพร้อมเวลาข้อมูลของสถานี, PM2.5 (µg/m³), AQI, ระดับคุณภาพอากาศตามเกณฑ์ คพ. พร้อมคำแนะนำ
- หน้า 2 แสดงกราฟ PM2.5 และ AQI ย้อนหลัง 24 ชั่วโมง ปัดซ้าย/ขวาเพื่อสลับหน้า หรือรอ 15 วินาทีให้สลับเอง
- กราฟเก็บจุดใหม่ทุกครั้งที่สถานีส่งข้อมูลรอบใหม่ และบันทึกลงหน่วยความจำของบอร์ด รีบูตแล้วกราฟไม่หาย แต่ตอนแรกกราฟจะมีจุดเดียวและค่อยๆ เพิ่มทุกชั่วโมง
- AQI ที่แสดงเป็นค่ารวมตามที่ Air4Thai รายงาน ซึ่งอาจมาจาก PM10 ได้ ใต้ตัวเลขจึงบอกว่า "จาก PM2.5" หรือ "จาก PM10"
- ไฟ Pilot lamp: เขียวเมื่อ AQI ไม่เกิน 50, เหลือง 51–100, แดงตั้งแต่ 101 ขึ้นไป และดับทั้งหมดถ้าขาดการติดต่อเกิน 20 นาที
- Seven segment: เขียนค่า PM2.5 × 10 (เช่น 27.2 เป็น 272) ผ่าน Modbus RTU ทุก 5 วินาที

## ต้องตรวจสอบกับอุปกรณ์จริง
- **Register ของ Seven segment:** ผมไม่รู้รุ่นและ Register Map ของจอคุณ ให้แก้ `SEG_SLAVE_ID`, `SEG_FUNC`, `SEG_REG_ADDR`, `SEG_SCALE`, `SEG_BAUD` ให้ตรงกับคู่มือ ถ้าส่งคู่มือมา ผมปรับให้ได้
- **การต่อสาย:** บอร์ด CYD มีขาที่ใช้ได้น้อย
  - RS485: TX = GPIO27, RX = GPIO35
  - Pilot lamp: เขียว = GPIO22, เหลือง = GPIO16, แดง = GPIO4 (16 และ 4 เป็นขาของ LED RGB บนบอร์ด ต้องบัดกรีสายออกมาใช้)
  - ห้ามต่อ Pilot lamp เข้า GPIO ตรงๆ ต้องผ่านรีเลย์หรือทรานซิสเตอร์
  - ถ้ามีโมดูล RS485 แบบไม่ใช่ Auto direction ให้ตั้ง `SEG_DE_PIN`
- **HTTP/HTTPS:** ถ้าเซิร์ฟเวอร์ redirect ไป HTTPS โค้ดตาม redirect ให้เอง และใช้ HTTPS แบบไม่ตรวจใบรับรอง
- **สระและวรรณยุกต์ไทย:** LVGL ไม่มี Text Shaping ผมจึงเลือกถ้อยคำที่ไม่ให้วรรณยุกต์ซ้อนทับสระบน (ระดับสีส้มใช้คำว่า "กระทบสุขภาพบางกลุ่ม") ชื่อสถานีที่ดึงมาจาก API อาจมีตัวอักษรซ้อนทับบ้าง
- **สีและทัช:** ถ้าสีเพี้ยนหรือปัดผิดทิศ ดูวิธีแก้ในคอมเมนต์ของ `platformio.ini` และ `TOUCH_ROT`
